# 轻舟 Skiff 0.3.4

主机卡片现在会显示注册时间、到期时间和剩余天数。到期前一周转为橙色提醒，过期后直接标出「已过期 N 天」。时间在主机设置里手动填写，精确到秒，也可以点「选择」按日期、时间两步挑。

主机设置新增「自动连接」开关，默认关闭。开启后，应用启动时会自动连上这台服务器。

同时把卡片收紧了一轮：终端／隧道／文件三个入口与 CPU／内存／带宽都压成一行，加上时间信息后，卡片反而比之前略矮。
